# Sales playbook & conversion rules

Winning product criteria for Sunnyeora:
1. **Visual Styling Appeal**: High visual impact in 3-second video clips (flowing dresses, textured knits, flattering fits).
2. **Healthy Margin Multipliers**: Sourcing costs allow 65%+ gross margin at retail pricing ($39 to $89).
3. **Reliable Fulfillment**: Dropshipped via Dropshipman / CJ with tracked express air shipping (7–10 days).
4. **Customer Objections Handled On-Page**:
   - *Fit/Sizing*: "True to size with generous relaxed stretch. Check our detailed size guide on each page."
   - *Delivery*: "Ships via USPS Priority / Royal Mail with live tracking provided via email."
   - *Returns*: "14-Day easy return guarantee if not completely satisfied."
5. **Abandoned Cart Strategy**:
   - Touch 1 (1 hour post-abandonment): Gentle reminder with cart summary.
   - Touch 2 (24 hours): 10% personalized discount code (SUNNY10).
   - Touch 3 (48 hours): Last chance urgency before cart expires.
